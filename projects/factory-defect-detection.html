Factory Defect Detection

Automated visual inspection for manufacturing quality control using YOLOv8, FastAPI, and React.

TypePortfolio Project
ScopeEnd-to-End Build
RoleAI Engineer

Self-directed portfolio project demonstrating production-grade AI delivery. Not a paid client engagement.

The Problem

Manual visual inspection in manufacturing is slow, inconsistent, and fatigue-prone — human inspectors miss defects and can only sample a fraction of output. This is a classic fit for automated computer-vision inspection.

The Solution

I built a full-stack visual inspection platform: YOLOv8 for defect detection, a FastAPI backend with REST endpoints, and a React dashboard for batch uploads and analytics — all containerized with Docker for one-command deployment. The code is open source on GitHub.

Key Challenges

  • Detection Accuracy: Trained and evaluated a YOLOv8 model for multiple defect classes, balancing precision and recall on real-world data.
  • Batch Throughput: Built a queue-based processing pipeline that handles multiple image uploads without blocking the API.
  • Production Readiness: Shipped the system as a Dockerized microservice with JWT authentication, Swagger docs, and CI/CD.
  • Observability: Added an analytics dashboard for defect rates, trends, and class distributions.
