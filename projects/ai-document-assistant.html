AI Document Assistant

LLM-powered document Q&A system with RAG pipeline for intelligent document understanding, retrieval, and analysis — built with LangChain and Hugging Face.

TypePortfolio Project
ScopeEnd-to-End Build
RoleAI Engineer

Self-directed portfolio project demonstrating production-grade AI delivery. Not a paid client engagement.

The Problem

Organizations sit on thousands of internal documents — policies, contracts, reports — but can't safely query them with AI. Public LLM APIs risk leaking confidential data, and keyword search misses semantic meaning.

The Solution

I built OpsAI — a self-hosted RAG assistant that runs a local LLM and a private Qdrant vector store, so answers come only from your own documents with source citations. It chunks documents intelligently, retrieves the most relevant passages, and refuses to guess when the knowledge base can't support an answer. The code is open source on GitHub.

Key Challenges

  • Document Chunking: Built a chunking strategy that preserves document structure for accurate citation.
  • Retrieval Quality: Implemented semantic search over a private Qdrant vector store with citation metadata.
  • Honesty Guard: Added a verification layer so the assistant refuses to guess when the knowledge base can't support an answer.
  • Privacy: Runs a local LLM so no documents ever leave your infrastructure.
