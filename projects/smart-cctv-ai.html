Smart CCTV AI

Real-time anomaly detection and behavior analysis for security surveillance using edge-optimized deep learning on NVIDIA Jetson Orin.

TypePortfolio Project
ScopeEnd-to-End Build
RoleAI Engineer

Self-directed portfolio project demonstrating production-grade AI delivery. Not a paid client engagement.

The Problem

Security teams are overwhelmed by camera feeds. Rule-based systems generate false alarms, while cloud AI adds latency and bandwidth cost. There is a clear need for on-device anomaly detection that runs where the cameras are.

The Solution

I built an edge-native AI pipeline that runs YOLOv8-based detection and behavior analysis directly on NVIDIA Jetson devices at the camera cluster. Video is processed locally and only alert metadata is sent to the central dashboard — no raw footage leaves the site.

Key Challenges

  • Real-Time Performance: Optimized YOLOv8 inference on edge hardware with TensorRT and INT8 quantization.
  • False Positive Reduction: Applied multi-frame temporal filtering to cut down false alarms while preserving sensitivity.
  • Multi-Camera Handling: Designed time-synchronized frame buffering to support multiple camera streams per device.
  • Low-Light Performance: Fine-tuned on a night-augmented dataset to improve detection in poor lighting.
